## About

*Faux ami* (French for "false friend") is a word that looks like an English word but means something completely different. *Librairie* isn't a library. *Préservatif* is definitely not jam.

**Faux Ami** turns that confusion into a game. You're shown a French word, you guess what it means, and you find out whether your English brain helped you — or betrayed you.

It's built for anyone: total beginners, people mid-Duolingo-streak, or anyone who's ever confidently said the wrong thing in Paris.

## How to play

1. A French word appears on screen.
2. Pick the meaning you think is right.
3. See if it's a true friend 🤝 or a *faux ami* 🎭.
4. Keep going and see how many you get right.

## Why I made this

I'm learning French myself, and false friends are some of the funniest (and most embarrassing) moments in the process. I wanted to make something short, replayable and genuinely cute — a small exploration in game feel, micro-interactions and visual charm, rather than a full learning app.

This is a one-off design-craft project: designed and vibe-coded end to end.

## Tech

Deliberately simple:

- **Single `index.html`** — HTML, CSS and vanilla JavaScript, no framework, no build step
- **Vercel** for hosting, auto-deployed from `main`
- **Vercel Web Analytics** for privacy-friendly visit counts

## Run it locally

```bash
git clone https://github.com/jahanvitiwariUX/Faux-ami-French-Game.git
cd Faux-ami-French-Game
open index.html        # macOS  (or just double-click the file)
```

That's it — no installs.
